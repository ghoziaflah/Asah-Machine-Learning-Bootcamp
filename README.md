# Asah Machine Learning Bootcamp

**Machine Learning Bootcamp Projects – Asah led by Dicoding & Accenture**

## About the Program

Asah is a machine learning bootcamp led by Dicoding in collaboration with Accenture, designed to develop practical skills in data analysis and artificial intelligence. The program covers data preprocessing, exploratory data analysis, machine learning algorithms, model development and evaluation, as well as hands-on applications through real-world case studies.

## Projects

| No. | Project | Description |
|---|---|---|
| 01 | User Sentiment Analysis of Access by KAI Mobile Application | Analyzed user reviews to identify sentiment patterns and gain insights into customer experience. |
| 02 | Transaction-Based Customer Risk Assessment | Applied machine learning techniques to assess customer risk based on transaction-related behavioral patterns. |
| 03 | RFM-Based Customer Segmentation | Used RFM analysis and K-Means clustering to identify customer segments and support targeted marketing strategies through an interactive dashboard. |

## Skills & Technologies

- Python
- Data Preprocessing & Exploratory Data Analysis
- Machine Learning & Model Evaluation
- Natural Language Processing
- Customer Segmentation & Clustering
- Data Visualization & Dashboard
